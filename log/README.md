# Artemis progress log

One dated Markdown file records each day on which the project progresses. Filenames use `YYYY-MM-DD.md`, based on the current date in `America/Los_Angeles`.

Each entry contains:

- Completed work and findings.
- What was learned and decisions that affect later work.
- Problems encountered and how they were fixed.
- Verification evidence and any unresolved issues.
- Tomorrow's tasks, supplied by the user after asking them.

Update the same day's file throughout the day. Keep prior entries as history and distinguish new results from carried-over context. If tomorrow's priorities have not been provided, record that they are awaiting the user's answer.

This workflow runs as part of our project work; there is no unattended daily scheduler.
