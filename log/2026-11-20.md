## What was learned

- State-dependent validation belongs on the serialized writer. A cache lookup before enqueue must not incorrectly reject a command whose preceding create is still queued, or skip a rejection sequence that should be durable.
- Every original batch record must be validated before deduplication, even when a later record replaces the same ID. A rejected batch must leave all user data unchanged.
- Consistent reads need matching index and storage views. Short-lived per-reader snapshots plus a precommit frozen view allow reads during fsync without retaining database-wide snapshots for idle collections.
- Snapshot readers must finish before close. Index-publication failures must mark a collection unavailable before releasing the publication lock, and failure cleanup must release its frozen snapshot.
- Registry lookups must not hold the global monitor while waiting for a collection lock; otherwise one busy collection can block unrelated reads.
- Validate both directions of durable ID mappings during recovery. A forward alias to another record's internal ID can otherwise allow deletion of the wrong record.
- Rank candidates using double precision, then narrow the reported float score. Narrowing before ranking can turn distinct large distances into equal infinities or tiny distances into equal zeros. Clamp normalized cosine similarity to its mathematical range to absorb float rounding.
- A useful p99 needs repeated observations, excluded warm-up/setup/reporting, a stated workload and retained raw samples. Correctness-test durations and injected fault delays are not normal API latency distributions.
- Measurements should run after validation activity finishes. A local closed-loop JVM/FlatIndex baseline is not a production SLO, native benchmark or HNSW result.

## Problems encountered and fixes

| Problem | Fix and verification |
| --- | --- |
| Missing-collection upserts failed before entering the writer, bypassing sequence consumption. | Made cache preflight optional for misses and left authoritative lookup to the writer; regression verifies the consumed rejection sequence. |
| Recovery accepted alias mappings, malformed persisted keys or nonunit cosine vectors. | Verify forward/reverse mappings, vector presence and stored cosine norms; map structural corruption to `INTERNAL` before READY. |
| Opening a default-family-only database could add Artemis column families to unrelated data. | Inspect the existing family layout before writable open; reject foreign/missing layouts without changing them. |
| Float overflow/underflow could produce incorrect nearest-neighbor ordering; normalization rounding could produce a negative cosine distance. | Compare wide scores, narrow only result values, and clamp cosine similarity; numeric regressions pass. |
| Long-lived snapshots pinned old data; failed publication could expose a partially changed index. | Use short-lived/frozen views, invalidate failed state under the write lock and drain readers before cleanup. Snapshot-retention and failure-isolation tests pass. |
| A registry lookup waiting on one collection stalled unrelated collection lookups. | Acquire collection leases outside the registry monitor; a controlled contention regression passes. |
| A failure-path test leaked its own read lease and hung. | Stopped only that task's test worker, corrected test cleanup, reproduced the intended production failures, then verified their fixes. |
| The small demo did not demonstrate the spec's edge cases or latency tails. | Added public-service boundary/operation/flag/lifecycle cases, an explicit coverage matrix, native/process checks and repeated latency measurements. |
| An early demo failure could import stale global JUnit XML and display old checks as current evidence. | Give each run a unique Gradle JUnit output directory and remove the stale-copy fallback; both early-failure regression fixtures pass. |
| Validation activity overlapped a preliminary benchmark. | Stopped and discarded that run; performed the final measurement after validation completed. The discarded run is marked FAIL and is not used below. |
